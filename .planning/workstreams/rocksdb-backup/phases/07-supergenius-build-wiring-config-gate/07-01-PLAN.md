## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| thirdparty install trees / release tarball -> SuperGenius & GeniusSDK builds | build inputs consumed at configure time; the CI variant arrives as a downloaded release artifact |
| option/cache variables -> every build leg | an unconditional find would silently make the superbuild chain a prerequisite of mobile and downstream legs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-7-01 | Tampering | CI ON-lane consuming thirdparty release tarball | medium | mitigate | Tarball-currency check (Task 2) writes a committed verdict; the CI ON-lane only wires against a verified-fresh tarball; stale/unverified falls back to local-evidence with a filed release-cut follow-up |
| T-7-02 | Tampering (build availability) | CommonBuildParameters.cmake consumption blocks | medium | mitigate | OFF-by-default option + IOS/ANDROID FORCE-off + committed OFF-configure log proving zero new finds in default builds (see prohibition P4 below) |
| T-7-SC | Tampering | package-manager installs | high | accept | No external packages are installed by this plan — every consumed artifact is produced in-repo by the thirdparty superbuild (nested submodules); no package-manager install task exists, so the blocking checkpoint has nothing to gate |

## API Coverage Decision (S3-client surface)

The installed S3-client surface consumed here is **construct-only** in Phase 7: `OpenMinioS3Client(S3ClientConfig)` with eager validation and zero network I/O. Its data-plane capabilities (PutObject, GetObject, List, HeadObject, conditional create-only put, bucket flush/pendingObjects) are deliberately NOT wired now — each is mapped to its consuming phase: put/drain to Phase 8, get/head to Phase 9, flush/pendingObjects to Phase 10 (ROADMAP v1.1). Decided: construction incorporated (this plan), data-plane deferred-with-roadmap-mapping, nothing silently unbuilt.
