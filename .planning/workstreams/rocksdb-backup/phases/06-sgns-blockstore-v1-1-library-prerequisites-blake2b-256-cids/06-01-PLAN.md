<objective>
Widen the shipped v1.0 sgns-blockstore library to accept blake2b-256 CIDs additively alongside sha-256 (LIB-01): link the ecosystem's real blake2b implementation (ipfs-lite-cpp::blake2 — the same object code sgns::common::getCidOf uses), add the 3-arg CidOf overload, widen the three per-backend hash gates to exactly {sha256, blake2b_256}, branch all six verify-on-put/get sites on the CID's own multihash, add the dag-cbor codec token, and prove everything with pinned known vectors plus a committed cross-check artifact against the real CRDT CID producer.

Purpose: Every CRDT DAG block is CIDv1/DAG_CBOR/blake2b-256 — the v1.0 sha-256 gate throws on the very first block. This removes the blocker library-only, with the conformance kit as the proof instrument, before any SuperGenius wiring (Phase 7).
Output: Widened library (CidOf 3-arg overload, three widened backends, dag-cbor token), extended conformance kit + guard tests, committed getCidOf cross-check evidence, CMake/superbuild blake2 wiring.
</objective>
