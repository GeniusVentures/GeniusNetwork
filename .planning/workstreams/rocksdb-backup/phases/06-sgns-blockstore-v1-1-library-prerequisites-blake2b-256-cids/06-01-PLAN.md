<objective>
Lay the blake2b-256 foundation for the sgns-blockstore library (LIB-01, wave 1 of the widening): link the ecosystem's real blake2b implementation (ipfs-lite-cpp::blake2 — the same object code sgns::common::getCidOf uses), add the 3-arg CidOf overload (D-04), and pin its correctness with independently derived known vectors plus a committed cross-check artifact against the real CRDT CID producer (D-02).

Purpose: Every CRDT DAG block is CIDv1/DAG_CBOR/blake2b-256 — the v1.0 sha-256-only CidOf cannot compose one. This plan proves the hash path end-to-end (payload → digest → CID → pinned literal, cross-checked against the real producer) with the build wired and Tier-1 green, before plan 06-02 widens the three backend gates, the six verify sites, and the conformance kit on top of it — and any SuperGenius wiring (Phase 7) after that.
Output: blake2 build wiring (root + src CMakeLists + superbuild entry), 3-arg CidOf overload (installed header + implementation), extended cid spike tests, hygiene-guard ban, committed getCidOf cross-check evidence.
</objective>
