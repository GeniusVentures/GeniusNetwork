<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| envelope artifacts → payout math | worker-attested stamps drive real money movement |
| escrow ledger → refund target | the refund address must be the escrow source, never attacker-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04-01 | Tampering | inflated worker stamps | mitigate | Cap: billable ≤ escrow_max always (design §2); over-attestation bounded to the declared max the requestor already agreed to |
| T-04-04-02 | Tampering | malformed settlement entries | mitigate | Filter: malformed envelopes excluded, honest paid, bad gets nothing; ALL-malformed refuses payout (fail-closed) |
| T-04-04-03 | Tampering | refund redirected | mitigate | Refund target is escrow_tx-&gt;GetSrcAddress() read from the ledger's own escrow transaction — never from result/envelope data; empty refundAddress + nonzero refund fails closed |
| T-04-04-04 | Repudiation | rounding disputes | mitigate | Deterministic integer path (llround milli-hours, floor shares, lexicographic tiebreak) — identical inputs yield identical outputs; recorded rate (elm_rate) + design §2 are the dispute reference |
| T-04-04-05 | DoS | division by zero | mitigate | billable_millihours == 0 (all windows zero/malformed) never reaches the proportional division — the zero-well-formed-windows refusal path guards it |
| T-04-04-SC | Tampering | package installs | accept | No new packages (D-003) |
</threat_model>
