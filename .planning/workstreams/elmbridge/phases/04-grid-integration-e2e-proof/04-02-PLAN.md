<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| task/subtask JSON → worker | elms[] work-item selection and stop strings arrive from job JSON the worker re-parses |
| input_uri fetch → prompt | prompt bytes fetched from an untrusted content-addressed source |
| envelope artifact → settlement | worker-attested stamps cross to the payout path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-02-01 | Tampering | work_item_id selection in ProcessElmWorkItem | mitigate | Selection scans the ALREADY parse-gated elms[] (charset ^[A-Za-z0-9_-]+$, uniqueness); unmatched ids fail MISSING_INPUT; ids never reach filesystem paths (artifact filename is &lt;work_item_id&gt;.json only after charset gate) |
| T-04-02-02 | Tampering | input_uri prompt fetch | accept | Fetch goes through FileManager's existing content-addressed loaders — same trust level as non-ELM input fetch; no new parsing of prompt bytes (opaque text) |
| T-04-02-03 | Repudiation | worker-attested stamps | accept | T-01-10 accepted residual: under-reporting hurts only the worker; over-reporting is capped at escrow max (the 04-04 cap); single-node v1.0 scope |
| T-04-02-04 | DoS | repeated cache construction failure | mitigate | Lazy construction caches the FAILURE too (do not retry-fail per subtask in a tight loop); map to terminal envelope per subtask — the queue drains rather than livelocks |
| T-04-02-05 | Tampering | terminal-envelope bypass | mitigate | Envelope-present test requires hash non-empty AND exactly 1 chunk hash — an envelope-ABSENT genuine failure still returns failure (no blanket success) |
| T-04-02-SC | Tampering | package installs | accept | No new packages (D-003) |
</threat_model>
