## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04 | Tampering | New CI annotation steps | low | accept | Steps only read local xunit files produced earlier in the same job and append to `$GITHUB_STEP_SUMMARY`; they introduce no new secrets, no new external HTTP calls, and no new write access beyond what "Run tests" steps already have -- a compromise here requires the same repo/CI access an attacker would already need to alter the "Run tests" step itself |
| T-04-05 | Denial of Service | Grep over xunit output | low | accept | `grep -rl` over a bounded, job-local `xunit/*.xml` directory; failure to match (grep exit 1) is explicitly handled by the `if` guard and does not fail the step or the job |
| T-04-SC | Tampering | npm/pip/cargo installs | n/a | accept | No new package-manager installs are introduced by this plan -- only new shell steps in an existing workflow file |
