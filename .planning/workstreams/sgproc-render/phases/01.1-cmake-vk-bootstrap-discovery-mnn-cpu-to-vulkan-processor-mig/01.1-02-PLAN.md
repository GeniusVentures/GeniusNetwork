<objective>
Migrate the 13 remaining CPU-backed MNN processors (14 `createSession()` call sites — `texturecube` has 2) from `MNN_FORWARD_CPU` to `MNN_FORWARD_VULKAN`, wrapping every migrated call in Phase 1's existing shared `VulkanInitMutex()` guard. Purpose: Complete the MNN CPU→VULKAN backend migration this phase was inserted to finish, closing the gap between "3 of 16 processors on Vulkan" and "all 16 on Vulkan, safely serialized."
Output: 13 modified processor `.cpp` files, each requesting the Vulkan backend and guarding session creation with the shared process-wide mutex.
</objective>
