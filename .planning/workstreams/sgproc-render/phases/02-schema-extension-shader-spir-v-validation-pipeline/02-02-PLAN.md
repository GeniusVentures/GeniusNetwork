<objective>
Vendor `shaderc` (GLSL→SPIR-V compilation) and `SPIRV-Tools`/`SPIRV-Headers` (mandatory `spirv-val` validation, vendored as a SEPARATE, directly-linkable dependency — NOT reached through shaderc's own internal, non-exported build tree) as pinned git submodules, following this project's existing `ExternalProject_Add` vendoring convention. shaderc ships no installed CMake package config (confirmed via `[CITED: github.com/google/shaderc/issues/1369, github.com/microsoft/vcpkg/issues/23208]` in 02-RESEARCH.md) — its target needs a hand-written `IMPORTED` target rather than a `find_package(... CONFIG REQUIRED)` call, a deliberate deviation from the Vulkan-Headers/Vulkan-Loader/vk-bootstrap pattern already established in this exact file.

Purpose: Plan 02-03's `ShaderCompiler` component links directly against `shaderc::shaderc` and `SPIRV-Tools::SPIRV-Tools`; nothing in this phase can compile without these targets existing first.
Output: Three new pinned git submodules; a shaderc::shaderc IMPORTED target and a SPIRV-Tools::SPIRV-Tools IMPORTED (or find_package'd) target, both configurable and buildable.
</objective>
