<objective>
Integrate artifact record construction and execution manifest assembly into `ProcessingManager::Process()`. After every processor invocation, compute per-artifact content hashes from raw output bytes, capture chunk hashes from the existing processor output, assemble a fully-populated ExecutionManifest, and return structured `ProcessOutput` instead of a raw hash vector. Build a temporary `ProcessingResult`-from-`ProcessOutput` migration adapter so existing callers work with zero changes (D-10). Then update the SuperGenius processing layer and remove the adapter in the same PR set (D-11, D-12).

Purpose: The Process() dispatch becomes the single point where typed artifact records are born — no loose byte buffers, no newline-delimited strings. The manifest captures everything for deterministic hashing, signing, caching, and verification. The migration adapter ensures existing callers don't break during development.

Output: Modified `ProcessingManager.cpp` (Process() rewrite), modified `processing_processor.hpp` (ProcessingResult adapter factory), updated SuperGenius caller.
</objective>

    ```
    inline ProcessingResult ProcessingResult::FromProcessOutput(const ProcessOutput& output) {
        ProcessingResult result;
        // Map combinedHash back to the old hash field
        result.hash = output.combinedHash;
        // Map artifacts back to the old output_buffers shape
        if (!output.artifacts.empty()) {
            auto buffers = std::make_shared<std::pair<std::vector<std::string>, std::vector<std::vector<char>>>>();
            for (const auto& art : output.artifacts) {
                buffers->first.push_back(std::string(art.resourceName));
                // Artifact raw bytes are NOT stored in Artifact struct (only hash).
                // The adapter maps resource names only — callers that need raw bytes
                // must use the new ProcessOutput.artifacts + separate buffer access.
                // This is acceptable for a TEMPORARY adapter (D-10: removed before ship).
                buffers->second.push_back({});
            }
            result.output_buffers = buffers;
        }
        // Map terminal state to error
        if (output.manifest.terminalState != TerminalState::Success) {
            ProcessingErrorStage stage = ProcessingErrorStage::UNSPECIFIED;
            switch (output.manifest.terminalState) {
                case TerminalState::Cancelled:     stage = ProcessingErrorStage::CANCELLED; break;
                case TerminalState::Timeout:       stage = ProcessingErrorStage::TIMED_OUT; break;
                case TerminalState::BudgetExceeded:stage = ProcessingErrorStage::BUDGET_EXCEEDED; break;
                case TerminalState::Error:         /* UNSPECIFIED */ break;
                default: break;
            }
            result.error = ProcessingError{stage, ""};
        }
        return result;
    }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Processor output bytes → Artifact contentHash | Raw output from potentially attacker-influenced job input; SHA-256 mitigates tampering |
| chunkhashes vector → Artifact::chunkHashes | Processor-produced hashes stored into artifact record; overflow protected by AddChunkHash bounds check (Plan 08-01) |
| ProcessOutput → ProcessingResult adapter | Adapter is TEMPORARY — removed before ship (D-10); no permanent attack surface |
| ProcessOutput → SuperGenius caller | New API surface crossing component boundary — type-safe structs replace raw byte vectors |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-10 | Tampering | Process() artifact construction | mitigate | contentHash computed from raw output bytes via sgprocmanagersha::sha256 — same code path as executor identity; no new hash implementation |
| T-08-11 | Spoofing | ExecutionManifest::executorIdentity | mitigate | Sourced from CapabilityValidator::GetSnapshot()->identityHash which is SHA-256 of capability snapshot (Phase 06 D-08) — cannot be forged without compromising the snapshot |
| T-08-12 | Information Disclosure | ProcessOutput::artifacts | accept | Artifact records carry resource names, pass IDs, hashes — no secrets. Raw output bytes stored separately by FileManager |
| T-08-13 | Denial of Service | Manifest assembly with many artifacts | mitigate | MAX_ARTIFACT_REFS=64 bound on output artifact count; Process() produces at most outputs.size() artifacts which is schema-bounded |
| T-08-14 | Elevation of Privilege | Migration adapter FromProcessOutput | accept | Temporary adapter (removed before ship per D-10) — maps fields from new to old shape; no auth escalation path |
| T-08-SC | Tampering | No new packages | accept | std::chrono and existing includes only |
</threat_model>
