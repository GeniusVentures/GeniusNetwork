Implement deterministic binary serialization for Artifact and ExecutionManifest structs — a fixed-field, little-endian, fixed-offset binary layout (D-04, D-05, D-06). Produce byte-identical output across two runs with identical inputs (ARTF-05). After serialization, compute the manifest's SHA-256 self-hash.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Artifact fields → SerializeArtifact() | String fields may contain bytes that affect serialization offset integrity — fixed-offset layout eliminates this risk |
| ExecutionManifest → ComputeManifestHash() | manifestHash field must be excluded to avoid self-referential hashing — zero-before-serialize, restore-after pattern |
| Serialized bytes → SHA-256 | Binary blob fed to existing sgprocmanagersha::sha256 — no new hashing code path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Tampering | SerializeArtifact string truncation | mitigate | std::min(strlen, MAX-1) bounds string copy; pre-allocated zero-filled vector ensures null padding — no buffer overrun |
| T-08-06 | Tampering | SerializeManifest manifestHash exclusion | mitigate | Save/zero/restore pattern on manifestHash before serialization; documented in action with rationale |
| T-08-07 | Repudiation | Deterministic serialization | accept | Purpose of the feature is deterministic output — non-repudiation is the goal, not a threat |
| T-08-08 | Information Disclosure | DeserializeArtifact | mitigate | Validates input size == TOTAL_SIZE before any memcpy — rejects truncated/malformed blobs |
| T-08-09 | Denial of Service | chunkHashCount > 1024 | mitigate | Deserialize reads exactly chunkHashCount * 32 bytes within the 32768-byte allocation — count validated against max during construction (Plan 08-01 AddChunkHash) |
| T-08-SC | Tampering | No new packages | accept | C++ standard library + existing sgprocmanagersha only |
</threat_model>
