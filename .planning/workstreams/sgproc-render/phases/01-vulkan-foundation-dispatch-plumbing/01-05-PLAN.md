<objective>
Fix `ParseBlockSize()`'s unconditional-`.value()` crash on model-less passes (DISP-01), add a new `PassType`-keyed dispatch map structurally separate from the existing `DataType`-keyed `m_processorFactories` map and route RENDER passes through it to `RenderProcessor` (DISP-02), and make `CheckProcessValidity()` require a shader config for RENDER passes instead of silently no-op'ing (DISP-03).

Purpose: This is the plumbing that makes a RENDER pass reachable and non-crashing through `ProcessingManager`, without which `RenderProcessor` (plan 01-04) is unreachable dead code. The `PassType`-keyed map must be structurally separate because `static_cast&lt;int&gt;(PassType::RENDER) == 3 == static_cast&lt;int&gt;(DataType::INT)` — reusing the existing map would silently misdispatch a RENDER pass to `MNN_Int`.
Output: `ProcessingManager.hpp`/`.cpp` changes, a new `processing_dispatch_test` covering all three DISP requirements.
</objective>
