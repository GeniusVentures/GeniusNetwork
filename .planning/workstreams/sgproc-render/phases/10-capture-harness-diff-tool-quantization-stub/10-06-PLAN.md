<objective>
Register a thin CTest smoke test alongside the existing conformance-suite convention, per ARCHITECTURE.md Pattern 5: it proves `capture_harness` builds, runs, and produces a well-formed file on whatever machine CI happens to run on -- it deliberately does NOT assert cross-machine hash equality (that is Phase 11's manual, multi-machine job). This plan also fixes a pre-existing wiring gap discovered during Phase 10 planning: `SGProcessingManager/test/` (containing the Phase 06-08 `capability`/`execution`/`artifacts` test suites) is not currently reachable from the main SuperGenius CMake build at all -- `SGProcessingManager/CMakeLists.txt` only ever calls `add_subdirectory(src)`, and no other CMakeLists.txt in the repository references `SGProcessingManager/test`. Without fixing this, the new smoke test this plan adds would silently never build or run.

Purpose: closes the loop on Phase 10's plumbing -- once this smoke test is green, future refactors of the 14 processor files or the capture file format cannot silently break `capture_harness` without at least one CI runner noticing.
Output: `SGProcessingManager/test/` reachable from the main build; `test/capture/` smoke test registered and passing.
</objective>

capture_smoke_test.cpp: `#include <gtest/gtest.h>`, `<processors/vulkan_gpu_probe.hpp>`, `<capture_file_format.hpp>`, `<cstdlib>`, `<filesystem>`, `<fstream>`. One `TEST(CaptureSmokeTest, HarnessProducesWellFormedFile)`: first, `if ( !sgns::sgprocessing::HasUsableVulkanDevice() ) { GTEST_SKIP() << "No usable Vulkan device found on this host; skipping this GPU-dependent smoke test, not failing it."; }` (mirrors the existing Phase 09 `GTEST_SKIP()`/`HasUsableVulkanDevice()` convention, since MNN inference on this codebase's Vulkan backend has the same GPU dependency as the render path). Build the command string `std::string(CAPTURE_HARNESS_PATH) + " --fixture-root \"" + FIXTURE_ROOT_PATH + "\" --fixture processing_datatypes/float-processing-definition.json --label smoke-mnn-float --repeat 2 --output-dir \"" + OUTPUT_DIR_PATH + "\""` (the MNN float fixture is chosen over the render fixture for this smoke test specifically because it needs no `--write-render-vertex-fixture`/vertex-data setup step); call `int rc = std::system( cmd.c_str() );` and `ASSERT_EQ( rc, 0 ) << "capture_harness exited non-zero"`. Using `std::filesystem::directory_iterator` over `OUTPUT_DIR_PATH`, find the single file whose name starts with `smoke-mnn-float_` and ends with `.cap`; `ASSERT_TRUE` exactly one such file exists and its size (via `std::filesystem::file_size`) is greater than 0. Read that file's bytes into a `std::vector<uint8_t>`, call `sgns::sgproccapture::DeserializeCaptureFile( bytes, out )`, `ASSERT_TRUE` it returns `true`, and `EXPECT_EQ( out.artifacts.size(), 1u )` and `EXPECT_EQ( out.combinedHash.size(), 32u )`. Do NOT assert anything about specific hash *values* or cross-machine equality -- per ARCHITECTURE.md Anti-Pattern 4, that would be a false signal from a single CI runner.
