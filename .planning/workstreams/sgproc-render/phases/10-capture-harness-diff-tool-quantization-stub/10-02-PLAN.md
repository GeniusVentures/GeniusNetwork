Each of these 6 files needs exactly 2 insertion points: one at its per-chunk hash call, one at its stitched-combined hash call.

Purpose: this is Phase 10's core plumbing-proving work -- exercising the new `sgprocmanagerquant` library and `ExecutionContext::rawOutputCapture` field (Plan 10-01) at real call sites, so Phase 11/12 never have to touch this insertion-point wiring again, only the quantization function bodies.
Output: 6 modified processor files, each quantizing (identity stub) and capturing at both its chunk-level and stitched-combined-level hash call sites.
</objective>
