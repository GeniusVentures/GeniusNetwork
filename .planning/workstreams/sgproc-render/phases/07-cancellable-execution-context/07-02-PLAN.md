if (deadlineMs > 0) {

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Job schema deadline_ms → boost::asio timer | Untrusted uint64_t from job definition drives timer duration |
| Processor thread → deadline timer thread | CancellationToken atomic flag shared across threads |
| Process() catch → RunTeardown() | Exception may leave Vulkan/MNN state unknown (D-17) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Denial of Service | deadlineMs from schema | mitigate | CapabilityValidator bounds-checks deadline before Process() (D-07: pre-execution reject). Upper cap (configurable, default 3600000ms = 1hr) in ProcessingManager before creating timer. |
| T-07-06 | Denial of Service | gpuMemoryBudget from schema | mitigate | Pre-execution reject only (D-07) — CapabilityValidator checks budget against VkPhysicalDeviceMemoryProperties. No runtime enforcement beyond processor's own checks. |
| T-07-07 | Tampering | FileManager::SaveASync on terminal condition | mitigate | Three-way check (CANCELLED/TIMED_OUT/BUDGET_EXCEEDED) before save loop. CancellationToken::IsCancelled() also checked as belt-and-suspenders. |
| T-07-08 | Information Disclosure | Progress event logging | accept | Progress events carry pass_id + stage + percent — no secrets. Logged at info level. |
