- `ProcessingManager::Create(json)` → `ASSERT_TRUE`

**ProcessingTest pattern** (see `StringInputProcessingTest` lines ~155-198, `Texture1DProcessingTest`, `BufferProcessingTest`):
- `PatchedJson("xxx-processing-definition.json")`
- `ProcessingManager::Create(json)` → `ASSERT_TRUE`

- Create `io_context`, `chunkhashes` vector, `output_locations` vector, `model_node` copy

- `ASSERT_TRUE(process_result.has_value())`
- `ASSERT_FALSE(process_result.value().empty())`
- `ASSERT_GT(chunkhashes.size(), 0)`
- Compare output to `xxx_output_pt.raw` reference with tolerance: `mean_abs_diff < 1e-3`, `max_abs_diff < 1e-2` (per Pitfall 5 in RESEARCH.md)
