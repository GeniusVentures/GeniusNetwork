## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-03 | Tampering | Wire-format misalignment if Serialize/Parse blend-field edits ever drift out of lockstep | high | mitigate | Both edits land in the same task (this plan's Task 1), same field order, both using the existing bounds-checked `ReadU8`/`ReadU32`/`fail()` pattern -- never a silent out-of-bounds read on a truncated/malformed buffer. |
| T-17-04 | Tampering | A job declares an out-of-range `blend_src_factor`/`blend_dst_factor` integer tag that doesn't correspond to any `BlendFactor` enumerator (only reachable via a hand-crafted wire-format buffer, not through the JSON schema's own string enum, which nlohmann::json_schema already rejects) | low | mitigate | `ToVkBlendFactor`'s post-switch fallback (`VK_BLEND_FACTOR_ONE`) prevents undefined behavior on any unmapped tag value, mirroring every other `ToVk*` mapping function's existing defensive-fallback convention in this file. |
| T-17-05 | Denial of Service | 64x64 render target, non-trivial clear color | low | accept | Well within `kMaxRenderDimension` (8192); identical risk profile to the already-accepted happy-path/lighting fixtures. |
