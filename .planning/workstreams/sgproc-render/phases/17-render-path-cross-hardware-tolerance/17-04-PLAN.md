## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| 17-03's parsed `textureWidth`/`textureHeight`/`textureBytes` -> `UploadTexture`'s size-vs-dimensions validation -> real GPU image/memory allocation | The load-bearing DoS boundary for this plan -- a mismatched declared-vs-actual byte count must never reach `vkCmdCopyBufferToImage`. |
| `m_textureImage`'s layout-transition barriers -> the single shared command buffer/submission | Getting barrier ordering wrong (skipping the UNDEFINED->TRANSFER_DST_OPTIMAL step, or reading from the image before the SHADER_READ_ONLY_OPTIMAL transition) is undefined behavior per the Vulkan spec, not merely a logic bug. |
