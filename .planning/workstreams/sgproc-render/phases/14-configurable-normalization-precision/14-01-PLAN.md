<objective>
Make the quantization utility's precision schema-configurable at its source: add `ResolveQuantScale`/`ResolveByteQuantMode` free functions to `quantization.hpp`/`.cpp` that read the job schema's generic `parameters` array (D-01/D-02) and resolve a validated `quantScale`/`byteQuantMode` value with a silent, exact-v2.1-behavior fallback on anything invalid (D-04/D-05/D-07/D-08). Change `QuantizeFloatBuffer`/`QuantizeByteBuffer` to take the resolved value as a new required parameter, replacing the current hardcoded `kScale`/no-op body.

Purpose: this is the single centralized mechanism every one of Plan 14-02's 21 call sites will thread a value through -- get the fallback/validation contract right here, once, before touching any of the 14 processor files.
Output: `ResolveQuantScale`/`ResolveByteQuantMode` in `quantization.hpp`/`.cpp`, 3-arg `QuantizeFloatBuffer`/`QuantizeByteBuffer`, a CMake fix so the new `generated/Parameter.hpp` dependency compiles, and an extended `quantization_test.cpp` proving every fallback/boundary case.
</objective>
