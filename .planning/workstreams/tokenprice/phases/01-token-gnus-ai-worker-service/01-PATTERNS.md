const cacheKey = new URL("https://token.gnus.ai/v1/prices");
cacheKey.searchParams.set("ids", [...ids].sort().join(",")); // sorted + deduped
cacheKey.searchParams.set("vs", currency);

response = await env.PRICE_COORDINATOR
  .get(env.PRICE_COORDINATOR.idFromName(currency)).fetch(doRequest);

Router responsibilities (from 01-02 notes): route table is `GET /v1/prices` only; 404 JSON error for unknown paths; 405 for non-GET; validation from `validate.ts` rejects **before** any cache or DO interaction (ASVS V5). Body re-use discipline: clone before `put`, never put a consumed response (Landmine 15).

### `src/coordinator.ts` (service — Durable Object, request-response + batch coalescing)

**Analog:** research-verified snippet — 01-RESEARCH.md **KF-4** (core shape, verbatim skeleton below) + KF-14 (modern class style)

```ts
import { DurableObject } from "cloudflare:workers";
import { FRESH_MS, BATCH_WINDOW_MS, MAX_IDS_PER_BATCH } from "./envelope";

interface Waiter { ids: string[]; resolve: (rows: Map<string, Row>) => void;
                   reject: (e: unknown) => void; }

export class PriceCoordinator extends DurableObject {
  private collecting: { ids: Set<string>; waiters: Waiter[] } | null = null;
  private inflight = false;
  private holdOffUntil = 0;                      // upstream 429/403 back-pressure

  async fetch(request: Request): Promise<Response> {
    // --- SYNCHRONOUS PROLOGUE: no await ⇒ atomic under input gates ---
    const { ids, currency } = parsePricesRequest(request);      // throws 400-shape errors
    const now = Math.floor(Date.now() / 1000);
    const rows = readRows(this.ctx.storage.sql, ids);           // sync SQL read
    const needed = ids.filter((id) => !rows.has(id) || now - rows.get(id)!.fetchedAt > FRESH_MS);

    if (needed.length === 0) {
      return envelopeFromRows(currency, rows, ids, now);        // fresh: no upstream, no join
    }
    if (Date.now() < this.holdOffUntil || this.inflight) {
      // cannot join an in-flight fetch; open/join a NEW collecting batch
    }
    this.collecting ??= { ids: new Set(), waiters: [] };
    if (this.collecting.ids.size + needed.length > MAX_IDS_PER_BATCH) { /* flush later batch */ }
    for (const id of needed) this.collecting.ids.add(id);
    const waiter = new Promise<Map<string, Row>>((resolve, reject) =>
      this.collecting!.waiters.push({ ids: needed, resolve, reject }));
    this.scheduleFlush();                       // setTimeout(flush, BATCH_WINDOW_MS) — idempotent
    // --- END PROLOGUE (first await is below) ---
    const merged = new Map([...rows, ...(await waiter)]);
    return envelopeFromRows(currency, merged, ids, now);
  }

  private scheduleFlush() {
    if (this.flushTimer) return;
    this.flushTimer = setTimeout(() => { this.flushTimer = undefined; void this.flush(); },
                                 BATCH_WINDOW_MS);
  }

  private async flush() {
    const batch = this.collecting; this.collecting = null; this.inflight = true;
    try {
      const fresh = await fetchUpstream([...batch.ids], this.env);   // MSW-intercepted in tests
      persistRows(this.ctx.storage.sql, fresh);   // INSERT OR REPLACE per id — partial-safe (D-10)
      for (const w of batch.waiters) w.resolve(pick(fresh, w.ids));
    } catch (e) {
      for (const w of batch.waiters) w.reject(e); // reject ⇒ callers fall to stale/error path
    } finally { this.inflight = false; }
  }
}
```

Non-negotiable rules baked into this shape (each traces to a pitfall):
- Registration into `collecting` happens **before the first `await`** — DO input gates make the prologue atomic (Landmine 1).
- Waiters rejected + batch cleared in `finally` — no poisoned pending map (Landmine 2).
- Rows persist **before** waiters resolve — durable before any client sees it (Landmine 3; eviction test guards).
- `setTimeout` (not alarms — too coarse for 15 ms) drives the window; recommend `BATCH_WINDOW_MS = 15`.
- `holdOffUntil = now + 60s` after 429/403; never retry sub-minute, never branch on `Retry-After`/`x-ratelimit-*` (they don't arrive — diagnosis) (Landmine 9).
- Caller-side: waiter rejection → if usable 60s–5min rows exist → 200 stale envelope (D-07); else structured 502 descriptor the Worker relays (D-08). **Nothing throws out of `fetch()`.**

**SQL schema (KF-5):**

```sql
CREATE TABLE IF NOT EXISTS prices (
  id        TEXT PRIMARY KEY,
  price     REAL NOT NULL,
  fetchedAt INTEGER NOT NULL          -- epoch SECONDS (D-11; seconds, never ms)
);
```

Write: `INSERT OR REPLACE INTO prices (id, price, fetchedAt) VALUES (?, ?, ?)` per returned id (partial CoinGecko response never clobbers older rows — D-10). Pruning (discretion, recommended): piggy-back `DELETE FROM prices WHERE fetchedAt < ?` on each successful flush. Routing: `env.PRICE_COORDINATOR.get(env.PRICE_COORDINATOR.idFromName(currency.toUpperCase()))` — one DO per currency (D-05).

it("coalesces concurrent overlapping id-sets into one upstream call", async ({ expect }) => {
  vi.useFakeTimers();
  const p1 = SELF.fetch("https://token.gnus.ai/v1/prices?ids=bitcoin,ethereum&vs=usd");
  const p2 = SELF.fetch("https://token.gnus.ai/v1/prices?ids=bitcoin,solana&vs=usd");

### Envelope Contract (normative — pins Phase 2/3)

**Source:** `.planning/research/pricing_coordinator.md` lines ~180–210 (verified this session — the design reference's JSON examples)

Happy path (`GET /v1/prices?ids=bitcoin,ethereum,gnus-ai&vs=usd`):

```json
{
  "currency": "usd",
  "prices": {
    "bitcoin": 61234.12,
    "ethereum": 3421.77,
    "gnus-ai": 0.0841
  },
  "fetchedAt": 1790719234,
  "age": 17,
  "source": "coingecko",
  "stale": false
}
```

Stale path:

```json
{
  "age": 94,
  "source": "coingecko-cache",
  "stale": true
}
```

Freshness bands: `0–60s fresh / 60s–5min stale but usable / >5min unavailable`. Error body (D-08): `502` + `{ "error": { "code", "message", "upstreamStatus"? } }`; `400` malformed; `404` unknown path; `405` non-GET; never 500.

**Apply to:** `envelope.ts` (builder), `index.ts` (router relay), every test file's response assertions. Phase 3 maps `source` → `PriceSource::CoinGecko` / `PriceSource::GnusPriceService` (D-06) — treat any envelope-field drift as a breaking contract change.

### Error handling

**Source:** D-07/D-08 + Landmines 2/8/9 — **Apply to:** `coordinator.ts`, `index.ts`, `upstream.ts`
Nothing throws out of `fetch()`; upstream failure with usable cache → 200 stale (D-07); nothing usable → structured 502 with `upstreamStatus` when CoinGecko returned an HTTP status (truthful diagnosis — unlike today's swallowed 403, per `/memories/repo/coingecko-price-api-frontend.md`). Only-200s cached; hold-off 60s after 429/403.

### Hermeticity (fail-closed egress)

**Source:** KF-2/KF-13 — **Apply to:** `vitest.config.ts` (outboundService guard), `setup.ts`/`server.ts` (MSW), `hermeticity.test.ts` (canary: unmocked CoinGecko path must not egress)
The suite's defining property; Phase 5's CI job inherits it.

### Secret handling

**Source:** D-04/D-05 + KF-9 — **Apply to:** `upstream.ts` (only reader), `key.test.ts`, `config.test.ts`, `pricecoordinator/.gitignore`
Optional `env.COINGECKO_API_KEY`; never in `wrangler.jsonc`, never in any response; `key.test.ts` asserts no-leak on all bodies incl. 502s.

### CI non-breakage

**Source:** `SuperGenius/.github/workflows/cmake.yml` (verified this session) — **Apply to:** Phase 1 constraints, Phase 5's future `worker-tests` job
Job shape: `resolve-runners` (runner availability probe) → `build` (`needs: resolve-runners`, 16-config matrix, `paths-ignore: [".github/**", "Readme.md"]` on push/PR triggers). **Phase 1 note:** since `paths-ignore` only lists `.github/**` and `Readme.md`, PRs touching `pricecoordinator/**` **will** trigger the full C++ matrix — that is existing behavior, not breakage; the code itself is CMake-invisible (D-03) so builds stay green. Phase 5 adds the `worker-tests` job with its own `paths: pricecoordinator/**` filter (only possible because of D-01) and may revisit the matrix trigger — out of scope now.
