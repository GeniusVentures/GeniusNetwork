## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network → subject handler | Rejection subjects from any peer are re-verified against local state before voting |
| certificate → escrow state machine | A certified rejection mutates escrow state and (regime 2) moves funds — quorum is the authority |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-08-07 | Tampering | rejection subject handlers | high | mitigate | Subject handler re-runs the gate and requires recomputed reason == reject_reason (D-08-06); CheckSubject drops empty refs / zero reason (08-02) |
| T-08-04 | Tampering | BuildRejectionReleaseTransaction | high | mitigate | Single output of the full amount to escrow GetSrcAddress only (D-08-07); UTXO double-spend rules make a second release structurally fail (D-08-05) |

| T-08-SC | Tampering | package installs | high | accept | No package installs this phase; in-repo only |
</threat_model>
