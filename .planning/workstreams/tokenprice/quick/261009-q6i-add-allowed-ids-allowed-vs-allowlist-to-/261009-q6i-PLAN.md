<objective>
Enforce an ALLOWED_IDS / ALLOWED_VS allowlist in the price-coordinator worker so token.gnus.ai cannot be abused as a general-purpose CoinGecko proxy (quota burn / shared rate-limit trips), while keeping the sole real consumer — the SuperGenius C++ LocalPriceManager, which requests only id genius-ai vs usd — fully working. Widenable later by editing wrangler vars (config change, no code).

Purpose: The deployed worker currently accepts ANY id matching [a-z0-9-]+ (up to MAX_IDS_PER_REQUEST=50) and any [a-z]{2,10} vs currency. A malicious actor gets a free CoinGecko proxy. This closes that hole with allowlist enforcement (SRVC-08 hardening), default-closed.

Output: Enforced validation in validate.ts wired from wrangler vars, test coverage (unit + router-level), config guard, DEPLOYMENT.md documentation, one commit on the SuperGenius submodule branch dev_price_validation.
</objective>
