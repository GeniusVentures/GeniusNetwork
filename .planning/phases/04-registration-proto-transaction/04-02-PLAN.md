<objective>
Wire the `RegistrationTransaction` C++ subclass into the full `TransactionManager` path — deserializer dispatch, `SendTransactionItem` CRDT write diversion to `reg/{child_addr}`, `RegisterChild` API with `GeniusNode` wrapper, and a minimal `FilterRegistration` element filter on the `reg/` CRDT namespace. Proven by an end-to-end GTest that a child wallet can create, sign, and submit a registration through the existing `TransactionManager` flow.

Purpose: Complete the vertical slice from Phase 4 Plan 01: the `RegistrationTransaction` class exists and compiles, but nothing can USE it. This plan connects all the dots — deserialization, submission, CRDT persistence, validation — so a child wallet actually CAN register.

Output: A child node can call `GeniusNode::RegisterChild(main_address, metadata, sequence)` and have a `RegistrationTx` flow through the full `TransactionManager` pipeline, written to `reg/{child_addr}` CRDT, validated by `FilterRegistration`, and observable as `SENDING` status with a valid `DAGStruct.nonce`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CRDT delta -> FilterRegistration | Untrusted peer can push any bytes into the reg/ namespace |
| SendTransactionItem -> CRDT Put | Local node writes RegistrationTx to reg/{child_addr} — key is derived from trusted child_addr |
| EnqueueTransaction -> consensus | RegistrationTx enters sgns.nonce.v1 pipeline; consensus validates signature + nonce |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Spoofing | FilterRegistration gate (b) — child signature | mitigate | RegistrationTx inherits CheckSignature() from GeniusTransaction. MakeSignature uses child's private key (secp256k1 ECDSA). FilterRegistration calls CheckTransactionAuthorization which verifies sig against DAGStruct.source_addr. Tampered signature -> tombstone reject. |
| T-04-05 | Tampering | FilterRegistration gate (a) — malformed proto bytes | mitigate | DeSerializeTransaction -> ParseFromArray fails on malformed protobuf -> returns error -> tombstone reject. Proto3 parser rejects invalid wire format. |
| T-04-06 | Tampering | FilterRegistration gate (c) — malformed main_address | mitigate | GetMainAddress().size() != 64 -> tombstone reject. Prevents injection of non-key garbage into reg/ namespace.
