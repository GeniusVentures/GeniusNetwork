## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | DeSerializeByteVector | mitigate | ParseFromArray returns false on malformed proto — return nullptr; caller must null-check. Follows existing TransferTransaction pattern. |
| T-04-02 | Denial of Service | DeSerializeByteVector | accept | Proto3 has built-in size limits (default 64MB). Oversized RegistrationTx bytes will fail ParseFromArray. No amplification vector — this is a leaf deserializer, not a recursion point. |
| T-04-03 | Information Disclosure | RegistrationTx.main_address | accept | main_address is a public key (by definition, public information). Proto wire format is not encrypted — same as all existing tx types. |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No new package dependencies. Proto compiler and C++ toolchain are pre-existing. |
</threat_model>
