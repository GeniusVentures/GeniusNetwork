Purpose: this is the main-initiated half of the lifecycle surface's adversarial coverage (Plan 04 covered the child-initiated half). Together, Plans 04-05 close CONTEXT.md's Test Depth requirement in full.
Output: Six new passing GTest cases in the existing `RegistrationTransactionE2ETest` fixture, using `account_`/`tm_` as MAIN and `child_account_` (via `CertifyChildRegistration`) as the certified child — mirroring the existing CONS-02/REGR-family tests' role assignment, since Revoke is main-initiated.
</objective>
