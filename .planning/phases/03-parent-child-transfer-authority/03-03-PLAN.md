<objective>
Add `TransactionManager::RecoverFromChild` and its `GeniusNode::RecoverFromChild` thin wrapper — the one new transfer-construction method this phase adds (D-62), building a `TransferTransaction` with `src = child_addr`, `dst = main's own address`, spending only the child's own UTXOs, and signed with main's own key so it can be approved by Plan 02's `CheckParentChildAuthority`/`CheckTransactionAuthorization`/`ValidateWitness` extensions.

Purpose: `TransferFunds`/`FillDAGStruct`/`UTXOManager::CreateTxParameter` all hardcode "the constructing account's own address is the tx's src and the UTXOs being spent are the manager's own" — none of that holds for a recovery transaction. This plan builds the child-scoped equivalents from the verified existing address-parameterized primitives (`GetUnconsumedUTXOs(address)`, `GetPeerNonce(address)`, `GetBalance(token_id, address)`) rather than reusing the main-scoped helpers unmodified.
Output: A working `RecoverFromChild` at both layers, ready for Plan 04's tests to exercise end-to-end.
</objective>
