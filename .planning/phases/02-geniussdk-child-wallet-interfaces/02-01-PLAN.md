<objective>
Expose `GeniusNode::RegisterChild` (auto-derived-sequence overload only), `GeniusNode::GetRegistrationsForMain`, and both `GeniusNode::GetChildBalance` overloads through the public GeniusSDK C API (`GeniusSDK.h`/`.cpp`), so external games/apps that link only `GeniusSDK.h` can register this node as a child wallet, discover a main wallet's registered children, and query child balances without linking SuperGenius directly.

Purpose: Completes the v2.2 milestone goal — the last mile from already-implemented `GeniusNode`/`TransactionManager` logic (v2.0, v2.1) to a consumable public C FFI surface.
